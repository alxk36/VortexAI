How traffic, the three agents and the Hacker fit together

Application traffic

Client → Gateway → Load balancer → Application → Database / Storage. Responses return to the client. Identity permissions govern access to resources; identity calls are control-plane events, not another hop for every request.

Security feedback

Attacker proposes a permitted scenario → bounded lab execution → observed events → Searcher evidence → Builder proposal → admin approval → replay.

Two environments

The in-memory simulation generates synthetic events. The isolated service lab uses disposable services and records their HTTP outcomes. Neither mode gives a model shell access or arbitrary network targets.

Model transparency

Agent results identify whether they came from a model or the deterministic fallback. A missing model connection does not become an AI success. Builder changes always require your approval.
